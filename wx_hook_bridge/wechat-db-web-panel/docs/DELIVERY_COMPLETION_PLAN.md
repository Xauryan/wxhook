## 默认边界

- 新发生的失败可自动分析；历史失败不批量收费转写，需手动发起。
- 不更改已有目标群、电话推送开关；新定时/提醒开关单独配置，首次启用不补发历史群消息。
- 推荐阶段时点为北京时间 12:00、16:00、18:30、21:00，可修改。
- AI 结果为待人工复核的建议，证据不足时明确展示，不自动归责或更改业务订单结果。
- 客户录音仅交给项目现有 ASR/LLM 服务，不写入意向单通知队列或外呼业绩表。
