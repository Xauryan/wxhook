# WeFlow 功能参考与本项目增量

参考：https://github.com/hicccc77/WeFlow ，核对版本 `2f23e72cebf7f309a0f4d129307d16d7b0cd41c3`（2026-10-15）。上游采用 CC BY-NC-SA 4.0。本轮按公开功能说明在现有 Python/React 架构中独立实现，没有复制其源码、界面素材或原生插件；既有 MIT 面板融合的许可说明继续保留。

## 功能对应

| 参考能力 | 本项目处理 |
| --- | --- |
| 实时聊天、解密快照、图片/视频/语音、撤回留存 | 保留现有聊天与快照实现 |
| 私聊统计、活跃热力图、关系网络、媒体统计 | 保留现有分析页面 |
| 年度与跨年度报告、双人报告、群聊画像 | 新增 `/analysis/reports`，支持全部年份/单年、会话选择、消息方向比例、月度/小时/类型/排行、连续活跃、最早留存与采样短句 |
| 个人足迹 | 报告中心选择“个人足迹”，仅统计我发出的记录 |
| 多格式批量导出 | 新增 `/analysis/exports`；JSON、CSV、HTML、TXT、Markdown、XLSX、PostgreSQL SQL、ChatLab JSON/JSONL 共九种格式；多会话/全部会话、日期和方向筛选 |
| 联系人导出 | 同一导出中心支持全部、快照通讯录好友、群聊、公众号、历史联系人候选；好友分类读取原生快照 `flag/local_type/delete_flag`，不从聊天次数推断好友关系 |
| 修改本地消息 | 保存本机修订副本和备注，原文不改；导出需主动勾选应用副本。包含原文、修改内容和备注的 `local-edits.jsonl` 随包保留 |
| 桌面弹窗、黑白名单 | 新增 `/analysis/notifications`；按账号保存、默认关闭、默认隐藏摘要，可设免打扰时段。浏览器权限由用户点击申请；应用须保持打开。未启用时全局提醒组件仅查询本地开关，不轮询原生微信状态 |
| 自动化导出 | 默认关闭，绑定当前微信账号与保存的筛选规则；每 1/6/24 小时执行，跟随同一账号的新快照，账号不匹配或离线时等待 |
| HTTP API | 保留现有 FastAPI 接口，新增 `/api/archive/*`。不是 WeFlow 5031 API 的兼容替换 |
| 朋友圈预览与备份 | 保留本项目朋友圈和备份实现；没有宣称拦截微信原生的删除/隐藏操作 |

## 运行与数据边界

- 报告和导出均从本地分析库读取；统计不代表微信当前所有数据。可识别发言人数不是群成员总数，首次记录不是双方最初认识时间，历史联系人候选不是已删好友结论。
- 页面统计使用独立进程执行 SQLite 扫描，与实时聊天 API 隔离；统计结果按账号/快照/筛选缓存两分钟，最多保留 48 份本地结果。
- 字数按文本字符计算；重复短句仅采样最近 20000 条长度 2–40 字符的文本，界面标出样本量。没有情绪、亲密度或关系状态推断。
- 导出后台进程独立于 API 生命周期，按批流式写入，保存进度、取消信号、进程身份和状态；重启后可读取任务状态，中断任务明确标为中断。未实现中断后的断点续传，应重新创建任务。
- 每个任务使用一个只读 SQLite 事务；绑定账号、快照时间和数据根目录生成的 scope，起止检查一致，发布时与快照任务共用发布锁。快照切换后旧范围结果不能通过当前范围下载。
- ZIP 完成前只生成暂存文件；失败、取消和中断不提供下载。ZIP 含 `manifest.json`，记录筛选、快照、行数、每个记录文件的 SHA-256 与边界。任务中间文件在结束时清理，完成的 ZIP 保留在项目 `.cache/archive-exports/`。
- 不导出媒体二进制，仅保留消息正文、文件名及链接。CSV 会防止单元格公式执行；XLSX 所有单元格按文本保存、超长/控制字符原文另存 `full-text.jsonl`，超过单表行数自动分表；HTML 使用转义和 CSP，不加载外部资源。PostgreSQL 文件只是 SQL 文本，不连接或写入任何数据库。
- ChatLab 遵循 [v0.0.2 公开交换格式](https://github.com/ChatLab/ChatLab/blob/main/docs/en/standard/chatlab-format.md)，JSONL 逐行写入。零消息会话不会输出不合规范的空 ChatLab 文件；实际第三方 ChatLab 导入仍须由目标应用验收。
- 本地副本采用原文哈希与 revision 校验；提醒只由首次入库、距当前不超过 120 秒的实时入站消息触发，不由历史导入、重放、自发消息或撤回通知触发。提醒失败不影响消息持久化与 ACK。
- 新增 Excel 依赖 `openpyxl>=3.1.5,<4`，按 `requirements.txt` 安装。没有新增云端模型、上传、遥测或外部消息发送。
- WeFlow 的原生解密与拦截组件未随参考仓库提供，本轮没有引入未验证的 DLL，也没有实现 macOS/Linux 原生桥接、微信内朋友圈删除/隐藏拦截、原生实况解密的新插件或外部 AI 服务。它们不属于已完成验收项。

## 验证

隔离 SQLite 测试覆盖报告口径、跨年、各格式回读、长文本、64 位 ID、公式/HTML/SQL 转义、副本 CAS、账号切换、取消、自动化时机与提醒规则；原始分析库逐字节保持不变。浏览器测试覆盖必选项、批量筛选、取消、失败状态与提醒默认关闭。构建保留旧资源，不清空用户工作树。

真实快照读回：2026 年报告计入 1,230,266 条消息，其中发送 57,686、接收 1,172,580，活跃 283 天；首次查询从约 36 秒优化到约 14 秒。真实下载、桌面/移动端与本地服务状态的最终结果记录于本轮 QA 文件，不能将模拟提醒测试当作实际系统通知送达。

2026-10-15 最终验收：相关后端 88 项、前端 309 项测试通过，TypeScript、增量 ESLint、格式检查和构建通过。常用入口 `http://127.0.0.1:5173` 上三个新页面的 1440px/390px 检查均无横向溢出、页面错误或控制台错误；双人、群聊、个人足迹切换和页面创建/下载真实 ChatLab 导出通过。真实文件回读验证了 ChatLab JSONL、XLSX 和包含 888 位快照好友的 CSV 及对应 SHA-256。

独立进程计算 2025 年 1,152,057 条消息报告约 15 秒；同期 30 次 API 健康检查全部成功，最大延迟 16ms，API PID 始终为同一个。验收后聊天桥接、接收、通讯录核验和发送开关正常；自动导出与提醒仍关闭。后台计算的首次耗时依赖数据量和本机硬件，不是性能承诺。未执行实际系统弹窗送达、ChatLab 目标应用导入或长周期定时运行验收。
