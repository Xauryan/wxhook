# 参考图测量

## 测量基线

- 前五张图片尺寸和 Playwright viewport：`1448x1086`
- 会话列表图片尺寸和 Playwright viewport：`1536x1024`
- `deviceScaleFactor`：`1`
- 浏览器缩放：`100%`
- 主题：浅色
- 坐标原点：图片左上角 `(0, 0)`
- 矩形格式：`x, y, width, height`，单位为 CSS px

测量使用原始 PNG 和边缘检测复核。表中的“可见边界”包含 1px 描边、阴影和抗锯齿外沿，CSS 盒模型通常需要向内收 1 到 3px。视觉回归优先保证卡片左上角、栅格间隙和基线对齐；动态真实文本长度不同不允许改变主要几何。

## 交互状态

- hover：卡片本身通常不抬升；可点击行使用极浅绿/灰背景。
- focus-visible：`2px` 微信绿外环和 `2px` offset，不依靠阴影暗示焦点。
- active：按钮背景加深但尺寸、边框宽度和文本位置不变。
- disabled：保留文字可读性，设置语义 `disabled`/`aria-disabled`。
- loading：骨架必须预留最终内容高度，避免图表和卡片跳动。
- empty/error：在原卡片内部显示具体原因和重试操作，不移除整个卡片导致栅格重排。
- reduced motion：关闭入场位移和大范围图表动画，保留即时状态变化。

## 响应式验收

桌面像素基线完成后验证：

| 宽度 | 验收点 |
|---:|---|
| 1024 | 侧栏可收窄；主要两列可变为单列或不等宽列；无页面横向滚动 |
| 768 | 侧栏转抽屉；顶栏搜索可折叠；表格提供卡片化或局部可访问滚动 |
| 375 | 单列卡片；筛选器分行；44px 触控目标；文字不小于 14-16px |

响应式不能通过整体缩放桌面页面实现。图表重算尺寸，列表保持键盘可达。

## Playwright 截图与 diff

固定流程：

1. 启动 API `127.0.0.1:8765` 和 Vite `127.0.0.1:5173`。
2. Chromium 按参考图使用 `1448x1086` 或 `1536x1024`、DPR 1、浅色主题。
3. 关闭浏览器动画并等待页面 `data-app-ready=true` 或网络稳定。
4. 依次打开六个路由并把截图写入 `artifacts/screenshots/`。
5. 与 `reference-images/` 的对应 PNG 逐像素比较。
6. 把差异 PNG 写入 `artifacts/diffs/`，报告差异像素数和比例。
7. 参考图永远只读；更新应用截图不能覆盖参考图。

## 无障碍检查清单

- 所有图标按钮有名称，图表有文字摘要。
- 颜色之外还有标签、数值、线宽或图案编码。
- 普通文字对比度至少 4.5:1；大字和非文本控件至少 3:1。
- Tab 顺序先顶栏，再侧栏，再主内容；抽屉打开后正确管理焦点。
- 图表点击筛选同时提供键盘可操作的列表或按钮。
- 灯箱、消息抽屉可用 Escape 关闭并把焦点还给触发元素。
- 375、768、1024、1448 宽度均无页面级横向滚动。
