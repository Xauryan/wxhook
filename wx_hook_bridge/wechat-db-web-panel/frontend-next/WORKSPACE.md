## 媒体边界

- 头像仅来自当前账号 head_image 数据库，本人、联系人、群成员分别按 username 查询；缺失时明确显示文字/群头像占位，不联网取头像。
- 图片支持已有普通格式、XOR/V1，以及当前桥接的本地 V2 解码；wxgf 内 HEVC 静态图经本机 FFmpeg 转 PNG。缩略图与大图/原图分别按需读取，解码结果保存在本项目缓存。
- 本次核对 `native/wx_hook_bridge/src/modules/media_ops.c` 的 decodeImage 实现：只读指定本地输入，输出到本项目缓存，不下载附件；但每次原生调用保留约 2 MiB arena。因此串行、按需且每个后端进程限制 64 次新原生解码，命中持久缓存不再调用。达到上限明确显示保护限制，不伪装为资源缺失。
- 不调用 downloadAttach 或其他原生下载接口，不批量下载、联网补拉媒体，不重启微信或注入 DLL。
- 本机 Silk 使用 pilk 转 WAV；其他音频/不兼容视频使用 FFmpeg 转 WAV 或 H.264/AAC MP4。FFmpeg 仅允许 file/pipe 协议、有限超时。未安装转换器、格式不支持、解密失败、缺失、未下载分别有状态。
- 文件路径只能来自已核验消息资源关联；阻止路径穿越、绝对路径、NTFS ADS 和跨根目录符号链接。资源 URL 绑定账号、消息、索引指纹；文件强制 attachment 和 nosniff，不执行文件，音视频支持 HTTP Range。
- 本地表情缓存支持经消息原图/备用 MD5 校验的账号级 AES-CBC 解密及 wxgf 转换；消息 CDN 密钥与本地缓存密钥分别处理。账号密钥仅从唯一桥接进程按已校验的 Weixin 4.1.9.23 访问器布局限量只读获取，读取前后核验账号/进程，不落盘、不暴露到接口；未知布局显示明确不可用状态，不改用远程 CDN 兜底。2026-09-22 的修复已通过 217 项相关测试和截图两条真实资源解码，运行 API 尚待手动重启，页面验收未完成，见 `../artifacts/sticker-fix-20260922.md`。
- 名片、位置与合并记录有结构化渲染；合并记录内部没有嵌入正文或附件的部分会显示不可用，不擅自联网获取。
