## 共享视觉语言

- 顶栏约 `68–70px`，左侧栏约 `186–200px`。
- 会话列表使用独立桌面壳：顶栏 `58px`、图标栏 `82px`、会话列表 `340px`。
- 主内容卡片为白色，`10–14px` 圆角，1px 极浅灰边框和轻阴影。
- 主色为微信绿，平坦区域约在 `#2f9458`、`#319457`、`#22934f` 范围；最终必须从原图无抗锯齿区域重新取样。
- 激活导航使用极浅绿色背景，主文字为近黑灰，辅助文字为中性灰。
- 字体外观接近 `Microsoft YaHei UI / PingFang SC / Noto Sans SC`。
- 各截图的侧栏宽度、主内容起点和卡片宽度有少量页面级差异。固定桌面基线下允许使用路由级 CSS 变量复刻差异，不要为了强行统一 Shell 而牺牲截图匹配。

## 页面映射

1. 概览：账号资料、KPI、30 天消息趋势、常聊联系人、消息类型环图、最近消息、年度热力图。
2. 联系人：关系网络、TOP 联系人、互动强度、首次互动增长、响应速度、关键联系人表。
3. 媒体：图片/视频/文件/链接统计、媒体预览、关键词、主题分布、文件表、搜索片段、链接和 OCR。
4. 贡献：年度贡献热力图、年度 KPI、当日统计、消息摘要和当日洞察。
5. 会话：账号级会话时间线、筛选器、小时热度、会话趋势和高频被引用消息。
6. 会话列表：图标栏、真实会话列表、完整消息流、联系人资料、会话热力图、文件和记录视图。

参考图中的“韩亮”、联系人姓名、头像和统计数字仅用于视觉表达，不是真实数据。正式页面必须读取当前解密数据库，不能硬编码这些示例内容。
